# Assets Required Before Building

Place these files here before running `eas build`:

| File                   | Size           | Required |
|------------------------|----------------|----------|
| icon.png               | 1024 × 1024 px | ✅ YES   |
| adaptive-icon.png      | 1024 × 1024 px | ✅ YES   |
| splash.png             | 1284 × 2778 px | ✅ YES   |
| notification-icon.png  | 96 × 96 px     | ✅ YES   |
| favicon.png            | 48 × 48 px     | optional |

See ICON_SPEC.md in the root folder for design guidelines.
